# A4 — 准入控制（Conservative Admission）

## 目标

原准入只看"当前装不装得下"，请求进来后因后续生成挤爆页池而被反复抢占，
重算做无用功。保守准入在**放行前预估整条生命周期的页需求**。

## 设计

- `_can_admit(seq)`（`admission_policy: "conservative"` 时生效）：
  `est_blocks = ceil((prompt_len + admission_gen_estimate) / block_size)`；
  要求 `available_slots + 已持有 >= est_blocks` 才放行，否则本轮跳过。
- 死锁兜底：全员被卡且无活可跑时，放行优先级最高的一条，避免调度器空转超时。
- `admission_gen_estimate` 可按负载的典型输出长度配置（默认 256）。

## 用法

```bash
python run.py --admission conservative --batch
```

## 验证

- 高压力负载（KV 池吃紧）对比 default/conservative：`preemptions_total` 计数、
  有效吞吐（完成 token / 总时间）、重算的 prefill token 浪费量。

## 简历条目

> 设计预测式准入控制：按 prompt 长度与估计生成长度预估 KV 需求，拒绝高抢占风险的准入，
> 显著降低 preemption 次数与重复 prefill 的算力浪费。
