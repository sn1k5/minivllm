# E5 — 全链路可观测（Prometheus 指标）

## 目标

不依赖 prometheus_client，自实现指标注册与文本渲染，覆盖调度、缓存、投机解码、offload 全链路。

## 设计

`src/metrics/metrics.py`：`Counter` / `Gauge` / `Histogram`（固定桶）+ `Metrics.render()`
输出标准 exposition 格式（`/metrics` 可被 Prometheus 直接抓取）。

指标清单（前缀 `minivllm_`）：

| 指标 | 类型 | 说明 |
| --- | --- | --- |
| request_total{ok,abort} | Counter | 请求计数 |
| prompt_tokens / generation_tokens_total | Counter | token 吞吐 |
| ttft_seconds | Histogram | 首 token 延迟 |
| itl_seconds | Histogram | 逐 token 间隔 |
| e2e_latency_seconds / queue_time_seconds | Histogram | 端到端 / 排队 |
| num_waiting / num_running / num_swapped | Gauge | 调度队列 |
| kv_cache_utilization | Gauge | KV 水位 |
| prefix_cache_hit / query_tokens_total | Counter | 前缀命中率 |
| preemptions_total | Counter | 抢占次数（A1/A4 效果观察） |
| spec_accept / proposed_tokens_total | Counter | 投机接受率（D1） |
| offload_* / swap_* | Gauge | 主机留档与换出统计（B1/A1） |

埋点位置：请求生命周期在 `AsyncEngine`（ttft/itl/e2e/queue），
队列与水位每步从调度器采集（dp=1 直读，多进程安全降级）。

## 用法

```bash
curl http://127.0.0.1:8000/metrics
# prometheus.yml scrape_configs 指向即可
```

## 验证

- 单测：计数/直方图分桶/render 格式。
- 集成：压测中观察 histogram 分位（PromQL `histogram_quantile(0.99, ...)`）。
